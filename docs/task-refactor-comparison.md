# 任务管理模块重构 - 前后对比

## 📐 整体架构对比

### Before（原架构）
```
用户入口分散 → 6个独立页面
├── /tasks/materialize (物化任务)
├── /tasks/sync (数据同步)
├── /tasks/transform (数据加工)
├── /tasks/metric (指标任务)
├── /tasks/pipelines (任务链)
└── /tasks/connections (搬运连接)

问题：
❌ 用户不知道该去哪个页面
❌ 找任务需要在4个页面来回切换
❌ 创建任务需要先确定类型才能找到入口
❌ "任务链"和"搬运连接"的定位不清晰
```

### After（新架构）
```
统一入口 → 分层清晰
├── /tasks (我的任务 - 默认入口)
│   └── 统一列表 + Tab筛选 + 高级搜索
├── /tasks/orchestration (任务编排)
│   └── 多步骤任务流水线管理
└── /tasks/connections (连接配置)
    └── 数据源连接信息

优势：
✅ 一个入口查看所有任务
✅ Tab快速切换，无需跳页面
✅ 功能分层明确：基础任务 / 编排 / 配置
✅ 符合用户心智模型
```

## 🎨 UI对比

**Before:**
```

-----------------------------------------------
| 表格: 只显示物化类型的任务               |
| [新建任务] 按钮                          |

```

**After:**
```
标题: 我的任务 [一页查看所有]
-----------------------------------------------

筛选: [搜索框] [状态▼] [本体▼]

| 类型 | 任务名称        | 本体      | 状态  |
|------|----------------|----------|-------|

改进：
✅ 一页看到所有任务

✅ 分页优化，支持调整每页条数
✅ 任务类型直观展示（Tag标签）

### 2. 创建流程

**Before（一步到底，容易出错）:**
```
┌────────────────────────────────┐
│ 新建任务 [关闭]                │
├────────────────────────────────┤
│ 制品类型: [下拉框]             │
│ 本体 / 对象: [级联选择器]     │  ← 用户困惑：什么是级联？
│ 目标数据库: [级联选择器]       │  ← 什么时候显示？
│ 字段1: [输入框]                │
│ 字段2: [下拉框]                │  ← 哪些是必填？
│ 字段3: [输入框]                │
│ ...                            │
│                                │
│      [取消]    [创建]          │
└────────────────────────────────┘
```

**After（向导式，4步引导）:**
```
步骤1/4: 选择任务类型
┌──────────────────────────────────────┐
│ ┌──────────┐  ┌──────────┐         │
│ │ ⚡ 物化  │  │ ↔️ 同步  │         │
│ │ 生成表   │  │ 同步数据 │         │
│ │ 场景说明 │  │ 场景说明 │         │
│ └──────────┘  └──────────┘         │
│ ┌──────────┐  ┌──────────┐         │
│ │ 🔧 加工  │  │ 📊 指标  │         │
│ │ 清洗转换 │  │ 计算指标 │         │
│ │ 场景说明 │  │ 场景说明 │         │
│ └──────────┘  └──────────┘         │
│                                     │
│          [上一步]  [下一步]         │
└──────────────────────────────────────┘

步骤2/4: 选择数据范围
┌──────────────────────────────────────┐
│ 本体 * [必填，有说明文字]          │
│ [下拉框: ERP v2 (published)]       │
│ 💡 本体是数据对象的集合...          │
│                                     │
│ 物化对象（可选多个）               │
│ [多选框]                           │
│ ☑ 对象·客户 → dim_customer        │
│ ☑ 对象·订单 → fact_orders         │
│ ☐ 关系·客户订单 → bridge_...      │
│ 💡 留空则物化全部实体              │
│                                     │
│          [上一步]  [下一步]         │
└──────────────────────────────────────┘

步骤3/4: 配置参数
┌──────────────────────────────────────┐
│ 💡 配置目标数据源和生成策略...      │
│                                     │
│ 目标数据库 * [级联]                │
│ 加载策略: [下拉: full / incremental]│
│ ...                                │
│                                     │
│          [上一步]  [下一步]         │
└──────────────────────────────────────┘

步骤4/4: 预览确认
┌──────────────────────────────────────┐
│ ✅ 配置完成                         │
│                                     │
│ 基本信息                            │

│                                     │

│                                     │
│ 💡 下一步操作                       │
│   - 任务创建后进入"草稿"状态       │
│   - 系统自动校验配置               │

改进：
✅ 每步只聚焦一个决策
✅ 进度条展示当前位置
✅ 帮助文本实时指导
✅ 预览环节避免配置错误
✅ 可以回退修改
